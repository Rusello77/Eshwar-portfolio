Design a mobile homepage UI for a community networking app for Indian homemaker entrepreneurs who run small home businesses (baking, pickles, tailoring, handmade crafts, homemade meals, beauty services).

The homepage should act as a community hub where users can:

ask questions

learn from others

discover nearby entrepreneurs

explore opportunities

celebrate community success

seek mentorship

The design should be minimal, friendly, and community-driven, using a green visual identity similar to the existing UI.

Design for mobile iPhone 14 size (390x844).

Visual Style

Maintain the existing aesthetic used in the app:

Primary color: green
Soft rounded cards
Light grey background
White content cards
Friendly tone

Style should feel:

Minimal
Warm
Community-oriented
Easy to scan

Use:

Rounded corners
Soft shadows
Generous spacing

Avoid:

Crowded layouts
Heavy visual decoration

Layout System

Use Auto Layout for all components.

Spacing:

8px
16px
24px

Corner radius:

12px–16px

Cards should have soft shadows and white backgrounds.

Homepage Structure

Create the homepage using the following section hierarchy in order.

Section 1 — Top Bar

Top of screen contains:

Search bar
Notification icon

Search placeholder text:

Search questions, people, suppliers…

Notification icon should show a small indicator dot if there are updates.

Section 2 — Primary Action

Below the search bar place a large primary button.

Button text:

Ask a Question

Style:

Green background
White text
Rounded corners

This is the primary CTA of the homepage.

Section 3 — Trending Discussions

Section header layout:

Trending Discussions View All →

The View All text should be a small green text link aligned to the right.

Below the header display 2 discussion cards as preview.

Each discussion card includes:

User avatar
User name
Time posted
Question text
Tag chips (example: Pricing, Marketing, Packaging, Suppliers)
Reply count
Helpful count

Cards should be rounded with subtle shadow.

Tapping View All should open a full Discussions page.

Section 4 — Stories from the Community

Section header:

Stories from the Community

This section should use horizontal scroll cards.

Each story card includes:

Profile image
User name
Business type
Short journey quote

Example:

Latha Nair
Homemade Pickles

"I started with 5 bottles during lockdown. Today I ship to 4 cities."

Add button:

Read Journey

These stories represent real business journeys of homemaker entrepreneurs.

Inside the story page include:

Business journey
Challenges faced
Lessons learned
Short business tips

Stories should feel inspiring and educational.

Section 5 — Community Milestones

Section header:

Community Milestones View All →

Show 3 milestone cards.

Examples:

🎉 Priya Sharma completed 100 orders

🌟 Meera Patel launched a new cake menu

📦 Kavita Singh expanded to online delivery

Cards should be small and celebratory.

Icons should add warmth and positivity.

Tapping View All opens the Community Activity page.

Section 6 — Nearby Entrepreneurs

Section header:

Nearby Entrepreneurs

Display horizontal scroll profile cards.

Each card contains:

Profile photo
Name
Business type
Distance from user

Example:

Meera Patel
Home Baking
2.3 km away

Buttons:

Connect
Message

Add a small secondary link below this section:

Explore Network Map

This link opens the radial network connections page.

Section 7 — Opportunities Near You

Section header:

Opportunities Near You View All →

Display 2 opportunity cards.

Each card includes:

Opportunity title
Location
Date
Participation cost if applicable

Example:

Indiranagar Festive Market
Dec 15
Booth fee ₹500

Button:

Apply

Tapping View All opens a full Opportunities page.

Section 8 — Mentor Homemakers

Section header:

Mentor Homemakers

Display horizontal scroll mentor cards.

Each card contains:

Profile image
Name
Business experience

Example:

Rashmi Kulkarni
10 years baking experience

Buttons:

Ask Advice
Book Chat

This section highlights experienced entrepreneurs willing to guide others.

Bottom Navigation Bar

Keep the bottom navigation consistent:

Home (active)
Connections
Collaborate
Learning
My Business

Active tab highlighted in green.

Interaction Flow

Implement the following navigation flows:

Homepage → Ask Question → Question screen

Homepage → Trending Discussions → View All → Discussions page

Homepage → Community Milestones → View All → Community activity page

Homepage → Opportunities → View All → Opportunities page

Homepage → Nearby Entrepreneurs → Explore Network Map → Connections map page

Homepage → Stories → Read Journey → Story detail page

Preview Limits

To keep homepage minimal:

Trending Discussions → show 2 cards
Community Milestones → show 3 cards
Opportunities → show 2 cards

Remaining content should appear in View All pages.

UX Principles

The homepage should follow progressive disclosure.

Show small previews of content and allow deeper exploration via View All navigation.

The page should feel like a living community hub, not a dashboard.

Users should feel:

Inspired
Connected
Supported

when browsing the homepage.

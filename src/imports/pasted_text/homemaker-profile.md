Design a full business profile screen for a homemaker entrepreneur in a community networking app.

Maintain the existing minimal green aesthetic, rounded components, and clean layout.
This screen should feel human-first, trustworthy, and action-oriented.

Design for mobile (390x844) using Auto Layout.

🧠 Core UX Logic (IMPORTANT)

The profile has two states:

🔒 State 1 — Not Connected (Discovery)

Show:

Connect
Message
❌ No phone number
❌ No email
❌ No WhatsApp

Add subtle hint:

“Connect to view contact details”

🔓 State 2 — Connected (My People)

Show:

Message
✅ WhatsApp button (primary action)
✅ Phone number
✅ Email
🧩 1️⃣ Hero Section (Story-First Entry)

Create a full-width hero section at the top.

Image
Large illustration (placeholder for real photo later)
Represent homemaker
Soft edges (rounded bottom or fade transition)
Background
Soft green tone or subtle dotted pattern
Keep consistent with existing design
Quote Bubble

Overlay a speech bubble with a short quote.

Example:

“I would be interested to learn things that would help grow my business”

Styling
Rounded bubble
White or soft grey background
Subtle shadow
Clean typography
Max 2–3 lines
🧩 2️⃣ Identity Section

Below hero:

Include:

Name (bold)
Business type
Location (area + distance)
🧩 3️⃣ Actions (Dynamic Based on State)
Not Connected:

Buttons:

Connect (primary)
Message (secondary)

Add small text:

“Connect to view contact details”

Connected:

Buttons:

WhatsApp (primary, green)
Message (secondary)
Contact Info (Only in Connected State)

Display:

Phone number
Email
🧩 4️⃣ About Section

Title:

About

Simple, personal tone

Title:

Products

Reviews

Availability

🎨 Design Guidelines
Use rounded cards (16px radius)
Maintain soft shadows
Keep spacing consistent (16–24px)
Use green as primary accent
Keep UI minimal and breathable
🔄 Interaction Behavior
Connect → sends request
Message → opens chat
WhatsApp → opens direct WhatsApp chat
🧠 UX Intent

This profile should:

introduce the person emotionally (hero section)
build trust (reviews, work)
enable connection (gated access)
support real-world interaction (WhatsApp-first)
🚫 Constraints

Do NOT:

add ratings or scoring systems
expose contact info before connection
clutter the hero section
introduce new visual styles
✅ Expected Result

A profile screen that feels:

Human
Trustworthy
Community-driven
Actionable

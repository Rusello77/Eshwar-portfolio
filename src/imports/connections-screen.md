Redesign the Connections screen of a mobile community networking app for homemaker entrepreneurs.

The current design uses profile cards, but the goal is to create a minimal and visually engaging network visualization interface inspired by radial connection maps.

The screen should feel calm, minimal, and elegant, consistent with the green UI aesthetic used across the product.

Visual Direction

Design style should be:

Minimal
Clean
Lightweight
Soft green accents
High whitespace

Avoid:

• card-heavy layouts
• crowded UI
• large photos

Focus on a visual network representation instead of a list.

Layout Structure

The screen should contain three main sections:

Page Header

Profession Filters

Radial Network Visualization

Section 1 — Header

Top of screen:

Title
Connections

Subtitle
Find homemakers with similar businesses nearby

Right side:

Search icon

Section 2 — Profession Filters

Below the header create a horizontal filter bar.

Filter chips represent homemaker professions:

Bakers
Pickles & Snacks
Tailoring
Handmade Crafts
Beauty Services
Homemade Meals

Design:

Rounded filter chips
Soft green background when active
White background when inactive

When a filter is selected:

Only those professionals appear in the network visualization.

Example:

If Bakers is selected, only bakers appear.

Section 3 — Radial Network Visualization

Create a circular network visualization inspired by orbit-style layouts.

Structure:

Center Circle
User's profile

Outer Circles
Potential connections

Design:

Center node = current user profile image

Around the center create 2–3 soft circular orbit rings

Place connection nodes evenly along these rings.

Each node is a small circular avatar illustration.

Use:

Subtle connecting lines between center and nodes.

Spacing should feel balanced and uncluttered.

Node Design

Each connection node contains:

Small circular avatar illustration
Soft shadow
Green outline when hovered or tapped

Nodes should be touch friendly but visually minimal.

Interaction Behavior

When a user taps a node:

Display a floating information card.

This card should contain:

Name
Profession
Distance
Area

Example:

Meera Patel
Home Baking
2.3 km away
Indiranagar

Buttons:

Connect
Message

The card should appear near the node with a soft animation.

Node Distribution Logic

Closest professionals appear in inner ring.

Farther professionals appear in outer rings.

Example:

Inner ring = within 2 km
Second ring = within 5 km
Outer ring = within 10 km

This visually communicates proximity.

Visual Details

Orbit rings should be:

Very thin lines
Light green color
Low opacity

Nodes should be:

White background
Soft shadow
Minimal avatar illustration

Keep the overall layout airy and spacious.

Microinteractions

Add subtle interactions:

Node hover expands slightly
Selected node highlights with green glow
Info card fades in smoothly

Bottom Navigation

Retain existing navigation:

Home
Connections (active)
Collaborate
Learning
My Business

Active tab highlighted in green.

Final Design Goal

The screen should feel like a visual community map of nearby homemaker entrepreneurs, rather than a list of profiles.

The experience should communicate:

Community
Proximity
Networking opportunities

while maintaining a minimal, calm, and modern interface.
